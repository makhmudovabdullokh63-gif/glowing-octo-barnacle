# ESP With Me — Frontend Prototype

## Files
- `index.html` — responsive homepage
- `style.css` — design system and responsive styles
- `script.js` — mobile navigation, carousel, keyboard controls and dynamic year
- `404.html` — fallback page
- `robots.txt`
- `sitemap.xml`

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Notes
This implementation follows the supplied ТЗ:
- responsive header and mobile menu
- Hero / About / Course Books / Features / How It Works / FAQ / CTA / Footer
- accessible buttons and keyboard carousel navigation
- responsive course-book carousel
- no invented reviews, statistics, partners, awards or achievements
- SEO basics
- semantic HTML
- focus states
- no external libraries or unnecessary dependencies

Real project images and exact existing ESP content should replace the prototype course-book covers/content once the current site's actual assets/content are available.
